# POC source media

Place licensed test media in `samples/input/` using these ignored filenames:

- `en.mp4`
- `ur.mp4`
- `hi.mp4`

Each file must be a readable H.264/AAC MP4, no larger than 1920x1080, and ideally 45–90 seconds. Collectively, the samples should cover male and female voices, one multi-speaker scene, light background audio, names, and business or technical terminology.

The repository intentionally contains no real customer or evaluation media. `matrix.example.json` defines all six required translation pairs.
